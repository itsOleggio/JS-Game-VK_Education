# JS Game: Arenas

Браузерный файтинг в стиле Mortal Kombat, написанный на чистом JavaScript в рамках учебного курса VK Education. Игрок управляет Скорпионом и сражается с Кунг Лао, которым управляет компьютер.

Проект не использует фреймворки и сторонние зависимости: только HTML, CSS и JavaScript (ES-модули).

[Открыть демо на GitHub Pages](https://itsoleggio.github.io/JS-Game-VK_Education/)

## Запуск

Игра использует ES-модули, поэтому браузер не загрузит её при открытии `index.html` напрямую через `file://`. Нужен локальный сервер:

```bash
git clone https://github.com/itsOleggio/JS-Game-VK_Education.git
cd JS-Game-VK_Education
python3 -m http.server 8000
```

После этого откройте <http://localhost:8000>. Подойдёт и любой другой статический сервер, например Live Server или встроенный сервер WebStorm.

## Как играть

1. В блоке **HIT** выберите зону удара: голова, корпус или ноги.
2. В блоке **DEFENCE** выберите зону защиты.
3. Нажмите **Fight**. Компьютер случайно выберет свой удар и защиту, после чего удары обоих бойцов будут рассчитаны за один раунд.
4. Бой идёт, пока здоровье хотя бы одного бойца не упадёт до нуля. Если это случилось с обоими в одном раунде, объявляется ничья.
5. Кнопка **Restart** перезагружает страницу и начинает новый бой.

Ход боя отображается в чате под ареной: там появляются сообщение о начале поединка и описания попаданий с временем, уроном и оставшимся здоровьем.

## Расчёт урона

У каждого бойца 100 HP. Каждой зоне соответствует значение силы, которое используется и для удара, и для защиты:

| Зона | Значение |
| --- | --- |
| `head` | 30 |
| `body` | 25 |
| `foot` | 20 |

Удар проходит, только если его значение больше значения защиты соперника. Урон равен разнице этих значений:

| Удар \ Защита | `head` | `body` | `foot` |
| --- | --- | --- | --- |
| `head` | блок | 5 | 10 |
| `body` | блок | блок | 5 |
| `foot` | блок | блок | блок |

## Структура проекта

```text
.
├── index.html                    # разметка арены и формы управления
├── style.css                     # стили
├── main.js                       # точка входа: бойцы, инициализация, подписка на форму
├── favicon.png
├── JavaScript/
│   ├── constants.js              # значения зон и список вариантов атаки
│   ├── createPlayer.js           # создание DOM-элементов бойца
│   ├── formSubmitHandler.js      # логика раунда и проверка конца боя
│   ├── logs.js                   # шаблоны сообщений чата
│   ├── player.js                 # класс Player (в игре пока не используется)
│   └── utils.js                  # логи, случайные числа, атака компьютера, HP, экран победителя
└── assets/
    ├── fonts/                    # шрифт Mortal Kombat 3
    ├── players/
    │   ├── avatar/               # аватары бойцов
    │   └── fightingStance/       # анимации боевой стойки
    └── *.png, fight.gif          # фоны арен и элементы оформления
```
